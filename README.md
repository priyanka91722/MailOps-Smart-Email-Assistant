# MailOps — Smart Email Assistant

MailOps helps you draft replies to pasted emails. Choose a tone and length, optionally add instructions, then generate, edit, and copy the reply. It does not connect to or send through Gmail.

## Features

- Professional, Friendly, Formal, and Concise tones
- Short, Medium, and Detailed reply lengths
- Optional instructions such as accepting an invitation or asking for an extension
- Editable generated reply, copy, and regenerate actions
- Request validation and readable configuration or service errors
- Health endpoint for checking the backend

## Architecture and request flow

1. The React interface submits an `EmailReplyInput` request to `POST /api/emails/generate-reply`.
2. Spring Boot validates the request and passes the email context, tone, length, and instructions to `EmailReplyService`.
3. Spring AI's `ChatClient` calls Google's Gemini Developer API using `GEMINI_API_KEY`.
4. Spring Boot returns the reply as JSON; the user can edit and copy it in the browser.

The API contract is kept in `lib/api-spec/openapi.yaml`. React Query hooks and schemas are generated from it. Email content is not persisted by this application.

## Technologies

| Technology | Where it is used |
| --- | --- |
| Java 17+ | Backend language |
| Spring Boot 3.5.6 | REST API, validation, CORS, and error handling |
| Spring AI 1.1.8 | Google GenAI chat model integration |
| Google Gemini API | Context-aware email reply generation (`gemini-3.5-flash-lite`) |
| React + TypeScript + Vite | Browser interface |

The Google GenAI starter and Spring AI 1.1 configuration properties follow the [Spring AI 1.1 Google GenAI Chat reference](https://docs.spring.io/spring-ai/reference/1.1/api/chat/google-genai-chat.html). The model identifier is listed by [Google's Gemini API model guide](https://ai.google.dev/gemini-api/docs/models).

## Prerequisites

- Java 17 or later
- Maven 3.8 or later
- Node.js and pnpm
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

## Configure the Gemini API key

In Replit, add `GEMINI_API_KEY` in **Tools → Secrets**. The value is read only by the Spring Boot backend and is never returned to the browser or included in logs.

For a local shell, copy `.env.example` as a reference and export the variables before starting the API:

```bash
export GEMINI_API_KEY="your-key-from-google-ai-studio"
export GEMINI_MODEL="gemini-3.5-flash-lite"
```

Do not commit a real key. If the key is missing, the generate endpoint returns HTTP 503 with a setup message instead of a fake reply.

## Run the application

In Replit, the managed workflows start the API and frontend. To start them manually in separate terminals:

```bash
pnpm --filter @workspace/api-server run dev
```

```bash
pnpm --filter @workspace/mailops run dev
```

Open the MailOps web preview. The app calls the API through the `/api` route.

For a standalone backend run or tests:

```bash
mvn -f backend/mailops/pom.xml spring-boot:run
mvn -f backend/mailops/pom.xml test
```

The React artifact workflow supplies the Vite `PORT` and `BASE_PATH` values. For a local standalone browser run, use the Replit preview or configure a local development proxy so `/api` reaches the Spring Boot server on port 8080.

## API

### `GET /api/health`

Example response:

```json
{ "status": "UP" }
```

### `POST /api/emails/generate-reply`

Example request:

```bash
curl -X POST http://localhost:8080/api/emails/generate-reply \
  -H 'Content-Type: application/json' \
  -d '{
    "emailContent": "Could we move our project review to Thursday afternoon?",
    "tone": "Professional",
    "length": "Medium",
    "additionalInstructions": "Accept the change and ask what time works."
  }'
```

Example response (the text varies because it is generated by Gemini):

```json
{
  "reply": "Thursday afternoon works for me. What time would be convenient for you?",
  "status": "success"
}
```

Supported tone values: `Professional`, `Friendly`, `Formal`, `Concise`.  
Supported length values: `Short`, `Medium`, `Detailed`.

## Demonstration examples

1. **Professional / Medium**  
   Email: “Could we move our project review to Thursday afternoon?”  
   Instructions: “Accept the change and ask what time works.”

2. **Friendly / Short**  
   Email: “Hi! I have the notes from yesterday's study group. Want me to send them over?”  
   Instructions: “Thank them and say yes.”

3. **Formal / Detailed**  
   Email: “Your assignment is due tomorrow at 5 p.m. Please let me know today if you need additional time.”  
   Instructions: “Request a one-day extension and do not make up a reason.”

## Tests and manual checklist

Run backend tests:

```bash
mvn -f backend/mailops/pom.xml test
```

The tests cover health, request validation, response JSON, prompt construction, and missing-key handling. AI-dependent tests mock the model and do not make external or paid calls.

Manual checklist:

1. Open the MailOps preview and confirm the backend status is healthy.
2. Submit an empty email and confirm inline validation appears without a request.
3. Paste one of the examples, choose tone and length, then generate.
4. Confirm the response is based on the pasted email and follows the selected settings.
5. Edit the generated reply and confirm Copy copies the edited text.
6. Change the instructions or tone and regenerate.
7. Temporarily remove `GEMINI_API_KEY` in a local environment and confirm the API returns a clear configuration error.

## Common errors

- **`GEMINI_API_KEY` is missing:** add it as a Replit Secret or export it in the local shell, then restart the API workflow.
- **Gemini returns an error:** check that the key is valid and enabled for the Gemini Developer API, and that the selected model is available to the account.
- **The frontend cannot reach `/api`:** in Replit, use the MailOps artifact preview so the project router can reach the API artifact; a standalone local Vite session needs a local proxy for `/api`.
- **Maven or Java is not found:** install Maven and Java 17+ and open a new terminal before retrying.

## Known limitations and future improvements

- Replies are drafts only; MailOps does not access inboxes or send email.
- Email content is not saved, so there is no reply history.
- The app relies on the Gemini Developer API and requires network access and a valid API key.
- A future version could add opt-in Gmail integration, saved drafts, and configurable signatures.
